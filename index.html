How to play

  • The top row is a guide — it shows the colour each column must end up as.
  • Tap any block in the same row or column as the empty slot to slide it in.
  • A whole run of blocks slides at once, so you can move several with one tap.
  • Swipe across the board to push blocks in that direction.
  • You win when every block matches the guide colour above its column.
  • One column keeps the empty slot — that colour has one block fewer.
  • Arrow keys work too: they push blocks in that direction.
  • Daily gives everyone the same puzzle each day — solve it to build a streak.
